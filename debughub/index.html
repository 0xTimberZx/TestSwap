DebugHub

Local diagnostics for TimbSwap — read live from this browser.

This view is local to your browser. The DebugHub SDK stores telemetry in localStorage, which is origin-scoped — so events logged on timbswap.xyz live here, not in the shared ecosystem hub on github.io. This page reads the same origin the app writes to, so it always reflects your own sessions on this device.
